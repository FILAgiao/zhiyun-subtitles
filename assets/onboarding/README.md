- `frog-feature-actions.png`：经用户选择的原始透明插画图集，1774×887，4 列 × 2 行。由内置 image_gen 参考用户提供的 `ads/v2/image-02-1280x800.png` 和 `image-05-1280x800.png` 生成。沿用绿色圆润青蛙、大眼、粉色脸颊与柔和立体质感，动作分别体现对应功能。

- `npm run build:onboarding`：从本目录 PNG 重新编码 WebP，需要现有 Playwright 和本机 Chrome，可使用 `PLAYWRIGHT_EXECUTABLE_PATH` 指定。
- `node build-userscript.cjs` 后运行 `npm run build:extension`：`load-onboarding-assets.cjs` 校验 WebP 文件并将图集内嵌进客户端，完整扩展离线展示，无需读取用户本机预览路径，无新增远程图片请求或权限。
