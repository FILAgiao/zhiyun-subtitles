## 0.20.31 修改记录（2026-10-11）

本次完整修复版 **0.20.31 已于 2026-10-12 发布到公网安装端点**，完整脚本和更新元数据均与本地构建逐字节一致。直接点击上方安装 / 更新链接即可更新，不必点击服务器页面的更新按钮。仓库根目录完整的 `zhiyun-subtitles.user.js` 可作为备用安装文件。

- **播放进度条统一**：智云 CMC 控制条是网站自绘控件，浏览器原生视频控件绑定在 `<video>` 内部。旧代码在缓存播放、拖动视频或“主看 PPT”布局中切换两套控件，导致外部控制条消失、内部进度条出现。现在在线与缓存均使用固定在视口底边的唯一外置播放条，使用浏览器原生范围输入框；原站控制条和视频内部控件统一关闭。它提供播放 / 暂停、时间、拖动跳转、音量、静音与倍速，拖动视频（包括暂时拖出视口）、切换 PPT 布局、全屏和返回在线均保持一致。
- **PPT 快速选页**：抽屉按内容高度向上展开，不再预留大块同步设置空间。横版、竖版、超宽页面均按原图比例确定缩略图尺寸，文字超出时省略；选页和跟随老师仍不跳转视频。
- **同步面板**：点击“字幕同步”后，下方标题为“字幕、PPT 同步”。字幕微调与 PPT 操作在主面板分行呈现；点击“PPT 此页”才展开当前页小预览，旁边的“＋”单独展开 PPT 提前 / 延后秒数、归零及换页校准。PPT 独立偏移按课程保存，不修改字幕偏移。“这页刚开始”校准仍要求在老师换页时使用。
- **AI 阅读位置**：生成过程中向上滚轮或滚动条阅读历史时暂停自动跟随；新增“回到最新回复”，点击或手动滚回底部才恢复跟随。最终完整回答也尊重阅读位置。

### 内存与开销检查

| 检查项 | 原因与处理 |
| --- | --- |
| 流式 Markdown / 公式渲染 | 原先每次增量都重新生成整段 DOM；现在合并到 80 毫秒窗口，完成时立即绘制完整正文，避免高速 token 更新产生大量临时节点。 |
| 图片放大预览 | 原先每次打开都把关闭闭包追加到长期清理数组，闭包继续引用已移除的预览和图片；现在只保留当前预览的清理函数，关闭即解除引用和键盘事件。 |
| PPT 缩略图 | 不再每 100 毫秒序列化完整页面数组；只在课程或页面列表改变时重建。可视区及相邻 220 像素范围的缩略图才持有图片来源，移出或收起时移除来源，切课断开观察器并清空旧节点。100 页回归中同时持有来源的缩略图少于 20 个。浏览器自身图片缓存何时回收由浏览器决定。 |
| 隐藏缓存控制条 | 停止每 100 毫秒更新已弃用的隐藏进度输入框和时间文字；由统一外置播放条显示状态。 |
| 大视频缓存 | 分段实现已有最多 4 个读取缓存块，默认每块 8 MiB，单个索引或片段上限 64 MiB，释放已使用的样本数据；保留该限制，避免改成整视频读入内存。640 MB 分块缓存单元测试通过。 |

以上是代码审查、交互回归与资源数量检查，并未承诺某个浏览器的实际常驻内存下降百分比。完整对话及附图仍保留，以保证历史问题和知识卡功能。

## 当前版本使用提示

按住中键，在当前页面原位置拖框、松开选定，然后点“发送提问”。只发送框内图片，不发送整页。取消不请求模型。

截图读取浏览器实际画面，不再重绘网页。独立扩展首次点击工具栏图标或 Ctrl + Shift + Y 授权当前标签页后，使用原生截图；油猴和未获标签页权限的扩展采用一次授权的浏览器共享会话，同一页面可连续截图，关闭对话后仍可使用，点击浏览器顶部的“停止分享”或离开页面结束；插件不再显示重复的常驻共享浮条。问此页直接将图片附到对话框；中键选区截图保留批注。系统截图可按 Win + Shift + S 后 Ctrl + V 添加。只有点击发送才向 AI 提交截图。

“新对话”会清空旧截图和 PPT 上下文，即使翻页记忆开启，简单文字问候也不会自动带图。需要图片时重新截图、粘贴或点击“讲解本页”。模型端使用 SSE 流式生成，油猴用短 HTTP 请求持续读取增量文字；无正文等待超过 45 秒会停止并给出提示，可自行重试。

## 0.17.0 改了什么

- **更清楚的界面**：统一品牌与标语；主要操作围绕字幕、讲解、截图。语音同步在右上角折叠显示，布局细节在设置，缓存按需展开。

- **缓存与 Chrome**：存储改为纯数据定位信息，避开本机 Chrome 153 读取 IndexedDB 文件系统句柄时的进程崩溃。旧缓存保留，恢复方式见下方。
- **缓存反馈与删除**：显示读取索引、准备片段、后台补齐等阶段及实际进度；停止写入后再删除文件，避免看似删除却仍在写入。
- **翻译更有上下文**：术语增强模式结合每侧默认 12 句、课程背景及术语表，仍只输出当前句；可切回逐句省流。选择双语才开始付费模型请求。
- **分别校准**：字幕使用语音匹配的分段同步点，定时校准默认关闭，手动微调立即停止自动任务。PPT 按视频进度和每课独立偏移跟随，不套用字幕偏移；底部“选页”可提前、延后或归零。老师刚换页时暂停视频、选中对应缩略图，点击“这页刚开始 · 校准”，随后自动跟随。偏移按视频进度秒数保存，无需按倍速换算。
- **AI 理解课程**：当前 PPT 讲解、框选/粘贴截图、多轮文字对话、解释模式与知识卡；翻页上下文可选，翻页本身不请求模型。

## 缓存与旧数据

缓存支持已授权、可访问的普通未加密 MP4；完整缓存也支持 WebM。分段缓存使用 MP4 索引确定可播放时间，不用文件百分比推算。10 / 20 分钟指课程时长，不是承诺的下载等待时间。

新版本不把文件夹句柄写进 IndexedDB。默认浏览器存储按名称重新定位；自选文件夹在刷新后需要重新选择。旧数据库不自动删除；Chrome 153 不直接读取旧记录以避免崩溃。设置中的旧缓存恢复入口说明可恢复范围，无法确定归属的旧分段保留，不自动拼接或覆盖。

保留课程标签页才能继续下载；清理浏览器站点数据可能删除默认缓存。已保存视频不等于整个课堂网站可离线打开。HLS/DASH、加密视频或浏览器不支持的编码不在当前适配范围。

## AI、凭证与费用

翻译与讲解共用用户保存在油猴中的豆包 Key，默认讲解/增强翻译模型为 `doubao-seed-2-1-lite-260915`，讲解模型可在设置中修改。示例中的 `$ARK_API_KEY` 是环境变量占位符，项目没有附带实际密钥。
