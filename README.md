# 🌱 伴读字幕 · 智云课堂

为智云课堂回放添加同步字幕、豆包翻译和可缩放 PPT 悬浮窗。纯油猴脚本，无需启动本地服务。

![界面预览（模拟课堂）](ui-preview.png)

## v0.14.1：缓存清单管理与播放跳转

- 每课增加「移出清单」（保留完整视频文件）和「删除缓存」（释放文件、保留课次记录）；下载期间先停止任务再管理。移出当前课后，本页不会立即自动加回，可手动再次加入。
- 使用缓存时启用视频原生控件，并在「视频缓存」中提供独立进度条、前后 10 秒按钮；焦点不在输入框、按钮或 PPT 翻页区域时，左右方向键可跳转。使用独立控件可避开网站原控件对本地 Blob 视频的兼容问题。
- 课程清单只读取 `seen:` 元数据，避免全库遍历时连带读取旧版视频 Blob。缓存来源退出、视频节点移除或被平台换源后释放对象 URL 和监听器；重复切换时替换尚未触发的加载回调。

这些是代码检查发现的资源管理改进，尚未通过整夜运行的内存采样确认用户报告的崩溃根因；不能据此承诺不再发生内存不足。网站播放器、浏览器扩展和视频解码也需实测排查。

登录过期不等于完整缓存文件被删除，但网页可能跳回登录页，后续下载请求也可能失败。当前仍为每次 8 MB 顺序写入磁盘，完整下载后切换本地文件；尚未实现部分缓存播放、跨刷新断点续传或独立离线课堂。

验证：30 项单元测试、模拟浏览器的左右键跳转/进度条/按钮及逐课删除回归通过。真实网站原控件兼容性和长时间内存曲线尚未实测。

## v0.14.0：打开过的课程批量缓存

「视频缓存 → 批量缓存 · 打开过的课」显示本机记录。更新后打开具体课次并加载视频，脚本会自动记录可缓存的 MP4/WebM 来源；也可点「加入当前课」。以前没有被记录的课需重新打开一次。

勾选多节课程后点击「缓存所选课程」，顺序下载到当前设置的缓存位置，显示当前课和 MB 进度，跳过可读取的完整缓存。单课失败继续下一课，失败项保持勾选便于重试；签名地址失效或 HTTP 403 时，重新打开该课并加入以更新来源。

保留执行队列的浏览器标签页。切换该页中的课程不会停止批量任务；停止队列保留已完成文件，当前未完成的一课重试时从头开始。刷新或关闭任务页会中断，记录仍在，但需重新勾选并开始。跨标签页的批量任务互斥，避免重复队列抢带宽。批量期间更改目录、导入或单独缓存需先停止队列。

视频完整下载后才能使用本机文件，**本版本尚不支持边下载未完成的文件边播放**。批量缓存仍会使用网络带宽，边看边缓存可能影响在线视频速度。课程来源（可能含临时签名）只保存在当前网站本机存储，不显示在列表或上传至第三方。

验证：30 项单元测试通过；模拟浏览器验证顺序执行、切课不中断、失败重试、跳过完整缓存、取消后重试、自动记录，以及切课时旧视频地址不串课。尚未对真实课堂批量下载做端到端验收。

## v0.13.0：直接调整画面与自动缓存播放

- 视频左上角「拖动视频」手柄随时可用，右侧下方的角标可缩放，无需进入设置；避开底部播放控件，画面其余部分仍可点击。PPT 保持直接拖动和边缘缩放。
- PPT 主讲模式的小视频默认靠右下角，进入全屏或窗口变化时重新定位，并留出 64 像素播放控件空间。手动移动后尊重自定义位置，重新切换布局可恢复默认。
- 字幕调整位于「偏好与连接 → 调整字幕」。
- 「视频缓存」默认开启自动使用缓存：完整下载后自动接续当前进度、倍速和播放/暂停状态；再次打开同课时也会检查缓存。切换来源会重新加载媒体，可能短暂等待，并非无缝拼接下载分片。
- 进度下方「缓存详情与诊断」可展开/收起，里面提供来源切换、清除、导入和存储位置设置。
- 默认缓存随浏览器配置目录存放，网页不能读取具体盘符。支持目录选择的浏览器可通过「选择缓存文件夹」选择 D/E 等盘；新缓存写入其「伴读字幕缓存」子目录。更改位置不搬迁旧缓存，旧缓存仍从原位置读取；再次打开时可能需要重新授权目录。

验证：30 项单元测试及模拟课堂浏览器回归，覆盖全屏右下角定位、窗口变化、直接拖动缩放、自动切换与暂停/倍速保留、目录句柄持久化及更改目录后读取旧缓存。目录选择器使用模拟入口，尚未在真实课堂与系统选择目录窗口中验收。

## v0.12.0：移除 512 MB 总大小上限

视频改用 HTTP Range 每次下载 **8 MB**，顺序写入浏览器私有文件系统（OPFS），缓存播放使用磁盘文件 Blob，不将整课读入 JS 数组。完成后才替换旧缓存；取消/失败会清理临时文件。中途关闭标签页后，下次缓存同一课程会清理未完成文件并重新下载，目前不支持断点续传。

开始时根据视频总大小检查浏览器可用空间（预留 32 MB），空间不足明确报错。需新版 Chrome / Edge 等支持 OPFS 的浏览器；服务器必须支持 Range。若服务器忽略 Range，大响应会中止并提示，不会退回整课内存下载。每块校验 Content-Range、大小及可用的 ETag / Last-Modified。旧版小视频缓存仍可读取。

验证：30 项单元测试，包括模拟 640 MB / 80 块下载、范围错误、文件版本/长度变化、空间不足和取消；浏览器测试验证真实 OPFS 写入、读取、切换来源和清除。真实课堂的大文件端到端下载仍待实际验证。

## v0.11.1 缓存修复

缓存下载改为油猴 `GM_xmlhttpRequest`，避免网页 `fetch` 的 CORS 限制；精确授权 `video.cmc.zju.edu.cn` 和 `interactivemeta.cmc.zju.edu.cn`。更新脚本时必须包含顶部元数据，首次连接需允许油猴访问视频域名。没有向视频请求附加翻译或语音 Key。

新增文件头校验，登录页/错误页面不会存为视频；HTTP 拒绝、权限、超时、文件过大和空间不足分别提示。「查看缓存诊断」显示域名、格式、状态，不包含完整签名地址。其他 CDN 域名和分片流仍需针对诊断适配，不假定平台有下载按钮。

## v0.11.0 更新

布局按钮可连续点击，依次切换：**左右并排 → PPT 主讲（右下角小视频，字幕在 PPT 下方）→ 恢复课堂**。PPT 保留自由拖动、四边缩放及复位；「布局与视频缓存 → 调整视频 / 字幕」可设置视频位置、宽高，以及字幕位置、宽度。切换布局不替换视频源。

校准开始时自动临时切到 1 倍速，结束或取消后恢复原倍速。首次成功立即停止；仅匹配失败才继续下一段，最多三段。采音遇到 `waiting` 缓冲事件时丢弃不完整片段，收到 `playing` 后重新采音，不重复提交损坏片段。主动暂停、拖动进度、换课或取消会停止校准。缓冲重启最多 10 次，单次等待最多 2 分钟，防止无限等待。

### 浏览器缓存（有适用范围）

在「视频缓存」点击「缓存当前视频」，完整写入磁盘后默认自动使用缓存。元数据保存在 IndexedDB，视频文件存入 OPFS 或所选目录。手动切换与清除入口位于「缓存详情与诊断」，也可导入自己的 MP4/WebM 文件。

- 当前只支持地址明确为 MP4/WebM、位于已授权域名且当前登录可访问的文件，总大小由浏览器剩余存储空间决定。浏览器存储空间不足时会报错。
- **不支持直接缓存 HLS/DASH 分片流、MSE 的 blob 地址或加密的资源。** 油猴可解决已授权视频域名的网页跨域读取问题，但不绕过服务器鉴权；不支持的来源请提供缓存诊断。
- 缓存完整下载前不会加速当前播放。需要保留课程页面以使用字幕和 PPT；视频数据本地播放不等于整站离线可用。
- 缓存在此浏览器的课程网站存储中，浏览器清理站点数据可能将其删除。不会上传本地导入的视频。
- 已使用模拟媒体字节验证存储、读取、切换来源、恢复及清除；尚未对真实课堂大文件、编码解码和网站播放器的缓存播放做端到端验收。

语言检测仍会跳过明确属于目标语言的字幕，复杂混合语言可能判断不准。

## 功能

- 将右侧已加载的语音识别字幕同步显示在视频下方，支持字号、位置和提前 / 延后调整。
- 一个下拉框切换原文与中英对照；选择中英对照后开启豆包按需翻译。
- 采集 12 秒视频音轨自动匹配字幕时间，第一次匹配成功立即结束；仅匹配失败时继续下一段，最多三段，可查看进度、随时取消。
- PPT 悬浮窗可拖动、拖右下角缩放，记住位置、大小与页码。支持跟随老师自动翻页，沿用字幕偏移。
- 支持容器全屏、设置面板收起、已加载字幕导出 SRT。

## 安装

1. 安装 Tampermonkey，并在浏览器扩展设置中允许用户脚本运行。
2. 打开 [脚本安装地址](https://raw.githubusercontent.com/FILAgiao/zhiyun-subtitles/main/zhiyun-subtitles.user.js)，按提示安装；也可在油猴中新建脚本，完整粘贴本仓库 JS 内容后保存。
3. 刷新智云课堂回放，打开右侧「语音识别」。面板版本应为 **v0.14.1**。
4. 「偏好与连接」可分别填写翻译 Key 和语音 Key。绿色勾表示已保存，不代表接口权限已经验证。

仅使用字幕显示、手动偏移或 PPT 悬浮窗时，无需 API Key。

## 翻译与语音

翻译使用火山方舟 Responses 接口，模型 `doubao-seed-translation-250915`。选择「中英对照 · 豆包翻译」开启请求，选择「仅原文」停止；刷新后默认原文。

语音校准使用 `openspeech.bytedance.com/api/v3/auc/bigmodel/submit` 和 `/query`，资源 `volc.seedasr.auc`，填写语音服务的 `x-api-key`。校准前播放视频并加载字幕列表；脚本会临时调整倍速。识别失败、取消或匹配不可靠时保留原偏移；它是局部偏移校准，不是全课逐字对齐。

Key 仅保存在油猴脚本存储中，不包含在仓库中。翻译会发送当前及后续少量字幕；校准会发送采集的视频音轨，不使用麦克风。两项服务可能产生 API 费用，取消浏览器等待不保证取消云端任务。不要把 Key 写进脚本或发到 GitHub Issues。

## PPT 与全屏

拖动 PPT 图片自由移动，拖右下角缩放，可跨越初始左右分区。悬停或键盘聚焦时显示翻页与跟随按钮。手动翻页暂停自动跟随，再次打开保留页码；开启跟随时按当前视频时间同步。

自动翻页依赖页面已加载的 PPT 时间戳。全屏请使用脚本的「专注全屏」；原生的仅 video 元素全屏不能显示外部 HTML 控件。PPT 图片保持原比例，空白区域使用黑色背景。

## 使用范围与限制

- 针对 `interactivemeta.cmc.zju.edu.cn` 回放页面的现有 DOM 实现，网站改版可能需要适配。
- 字幕导出仅包含已加载内容，结束时间由下一条字幕和最长显示时间估算。
- 浏览器或视频跨域限制可能阻止音轨采集。
- 使用者需自行拥有课程访问权限及相应服务权限；脚本不绕过登录或访问控制。

## 开发与测试

需要 Node.js 18 或更高版本。

```sh
npm test
npm install
npx playwright install chromium
npm run test:ui
```

`npm test` 运行无外部依赖的 30 项单元测试。UI 测试使用模拟课堂、虚拟凭证和模拟接口，验证字幕状态、PPT 翻页与跟随、窗口拖拽缩放、全屏、进度和取消，不调用真实云端服务。测试生成 `ui-preview.png`。

可用 `PLAYWRIGHT_MODULE` 指定已有 Playwright 模块路径，或用 `PLAYWRIGHT_EXECUTABLE_PATH` 指定 Chromium 可执行文件。
