# 每篇文章的交付检查

- 原稿存档；标题、链接、数字、活动权益与用户提供信息一致。
- 分清商店公开版本、开发测试版本、文章交付版本，不能互相代指。
- 功能图与原件有对应，文件名无空格，图片完整可打开；封面不遮挡重要文字。
- 手机短段落，关键词不过度强调；AI 图不充当运行截图。
- 写作评分和 HTML 合规验证均保存原始结果；不为提高评分虚构数字。
- 用技能官方渲染器生成正文和复制预览，不手改 HTML 产物。
- 预览图片已加载、布局无横向溢出，复制不带工具栏。
- 本地图片进入微信素材库后再检查公众号预览；本地复制成功不代表图片已上传。
- 摘要、封面、图片顺序及发布状态说明齐全。
- README 和 CHANGELOG 同步记录版本、原因、变化、验证与实际发布状态。
