# 品牌与公众号素材库

这里保存项目已提供素材的原样副本，方便以后文章复用，不删除或改写原件。

- `features/`：七张功能宣传图；正文按缓存、同步、双语、同屏、AI、截图、知识卡顺序使用。
- `covers/`：项目原有横幅、小尺寸宣传图；保持原比例，未经裁切或拉伸。
- `brand/`：产品标志和青蛙功能图集，原样备份。
- `extras/`：用户项目中的叙事图和翻译方案备选，主稿未全部使用。
- `catalog.json`：文件来源、尺寸、哈希、用途及本篇是否选用。
- `project-image-inventory.json`：已有宣传素材和界面预览的路径索引，未全部复制进库。

本篇优先选用不含真人照片的专业翻译示意图；未把其他人物版本作为课程真实截图。功能宣传图属于产品示意，不表示本轮连接学校课堂完成了功能实测。

现有卡通、表情 GIF 和真人照片的第三方权利未在项目内查到证明，只作项目原件归档，不默认扩展为可商用授权。以后选图时可查看原始来源；本篇未使用这些表情和真人版本。新生成原创封面会另存到文章目录，保留提示词与生成记录。
