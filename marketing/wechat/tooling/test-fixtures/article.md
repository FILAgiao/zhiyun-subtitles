# 小奶蛙的上课小工具

小奶蛙把**课程笔记与问题**放到一起，方便复习。

## 一起看看小工具

这是一份本地排版样例，**只验证结构与样式**。

### 把问题记下来

- 看一页课件。
- 记一个问题。
- 留一张知识卡。

> 先理解，再保存；复习时回来看看。

| 内容 | 用途 |
|---|---|
| 课件 | 对照课堂内容 |
| 知识卡 | 保存自己的笔记 |

```python
def review(question):
    if question:
        return "**保存知识卡**"
    return None
```
