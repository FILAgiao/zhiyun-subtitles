# 0.20.35 截图上线验收

自动化已验证 67 项核心测试、5 项扩展单元测试、加载后的 MV3 通信与跨域像素传递测试、共享会话复用和取消清理。MV3 像素测试使用限定的原生接口测试桩；浏览器真实的 activeTab 授权需要以下人工验收。

1. 解压 dist/zhiyun-subtitles-0.20.35.zip，在 Chrome / Edge 扩展管理页开启开发者模式并加载已解压扩展。只启用一份脚本或扩展；登录可用账号。
2. 打开普通网页或 B 站首页，点击浏览器工具栏中的扩展图标。预期直接将当前可见页面附到对话框，无屏幕共享选择器、无圈画窗口，图片与屏幕的跨域图片 / 视频画面一致。只附图，不调用模型。
3. 关闭对话，再点页面里的“问此页”。预期同一标签页继续原生截图。工具栏图标授予 activeTab 临时权限，页面内按钮本身不授予该权限。
4. 切换到另一个未授权的网站标签页，直接点页面里的“问此页”。预期需要选择当前标签页进行浏览器共享；授权后连续截图与关闭 / 再打开对话不重复请求授权，浏览器共享标记保持显示。
5. 按中键拖动：选框立即响应，松开取图，预览中可圈画和撤销。问此页始终直接附图。
6. 点击“停止共享”，检查浏览器共享标记消失；再次截图重新授权。刷新、离开页面、浏览器停止共享后同样释放资源。
7. 若浏览器要求重新点击以取得授权，页面显示“授权并截图”按钮；点击后能重试。拒绝或取消后可再次截图，不出现旧图覆盖新图。

默认快捷键为 Ctrl + Shift + Y。若浏览器或其他扩展占用，请在扩展快捷键设置中重新分配；工具栏图标不受快捷键冲突影响。
