# 0.20.36 截图上线验收

自动化已验证 67 项核心测试、5 项扩展单元测试、加载后的 MV3 通信与跨域像素传递测试、一次性共享、全屏尺寸恢复和取消清理。MV3 像素测试使用限定的原生接口测试桩；浏览器真实的 activeTab 授权需要以下人工验收。

1. 解压 dist/zhiyun-subtitles-0.20.36.zip，在 Chrome / Edge 扩展管理页开启开发者模式并加载已解压扩展。只启用一份脚本或扩展；登录可用账号。
2. 打开普通网页或 B 站首页，点击浏览器工具栏中的扩展图标。预期直接将当前可见页面附到对话框，无屏幕共享选择器、无圈画窗口，图片与屏幕的跨域图片 / 视频画面一致。只附图，不调用模型。
3. 关闭对话，再点页面里的“问此页”。预期同一标签页继续原生截图。工具栏图标授予 activeTab 临时权限，页面内按钮本身不授予该权限。
4. 切换到另一个未授权的网站标签页，直接点页面里的“问此页”。预期需要选择当前标签页进行浏览器共享；授权后取得一帧即结束共享，预览 / 对话出现前全部轨道停止；再次后备截图重新授权。检查共享栏收起后再全屏无整页旧截图或白卡遮罩，批注保持比例。
5. 按中键拖动：选框立即响应，松开取图，预览中可圈画和撤销。问此页始终直接附图。
6. 共享结束应自动发生，无须用户点“停止分享”。另在尚未取帧时手动停止 / 取消，检查截图终止；授权迟到、刷新、离开页面与销毁也须释放所有轨道。
7. 若浏览器要求重新点击以取得授权，页面显示“授权并截图”按钮；点击后能重试。拒绝或取消后可再次截图，不出现旧图覆盖新图。

默认快捷键为 Ctrl + Shift + Y。若浏览器或其他扩展占用，请在扩展快捷键设置中重新分配；工具栏图标不受快捷键冲突影响。
