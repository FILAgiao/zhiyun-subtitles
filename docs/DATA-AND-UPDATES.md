# 数据保存与更新说明（2026-10-28）

本说明依据 0.20.90 完整测试构建核对；本轮免登录和画廊改动尚未部署。当前交付是 Chrome / Edge 加载已解压扩展的测试包，未宣称已上架商店。

| 数据 | 保存位置 | 更新时的行为 |
| --- | --- | --- |
| 字幕显示、面板、AI 默认模板选择、时间校准选项 | 扩展 `chrome.storage.local`；油猴版使用脚本管理器 GM 存储 | 同一扩展 ID 的正常更新/重新加载保留 |
| 登录令牌 | 扩展 `chrome.storage.local` 的 `gateway-account-v1` | 更新不主动清除；服务端当前登录会话有效期 7 天，过期需要重新登录 |
| 登录账号、权限、额度、会话令牌摘要 | 后端 SQLite 数据库 | 与扩展安装文件分开，更新扩展不删除账号 |
| 个人提示词正文 | 后端账号提示词表 | 登录后读取，本地仅保留选择和旧版待导入内容 |
| 问答与截图的本机记录 | GM / `chrome.storage.local`；未关闭标签页的会话状态另有页面 `sessionStorage` | 更新不删除已归档本机问答；尚在生成的任务可能被页面刷新中断 |
| 网页问答 | 后端账号学习记录表 | 旧版仅点击“保存到账号”上传；0.20.87 已登录并确认归属的新对话自动同步文字，旧对话主动续聊后可绑定当前账号，失败状态保留并可重试 |
| 网页图片收藏 | 后端 `study_clips` 表 | 主动收藏后存入账号；不因为文字自动同步而自动上传截图 |
| 视频缓存 | 页面来源的 IndexedDB 索引和 OPFS 磁盘目录，或主动选择的本机目录 | 与扩展设置分开；清理网站数据或移动外部目录可能使缓存不可用 |

当前 ZIP 测试扩展没有商店自动更新渠道，也没有 `update_url`，因此需要手动覆盖原目录内的文件，再在浏览器扩展管理页重新加载，最后刷新课堂页面。请保留原目录、原扩展 ID，不要先卸载或另开目录安装来代替更新；后者可能变成另一份独立扩展。插件代码没有自动卸载逻辑。未来商店版可由浏览器自动更新，但商店版与测试版若 ID 不同，需要单独处理本机数据迁移。

正常更新不会主动删除 `storage.local`。卸载会删除该扩展的本机数据；换浏览器配置、换扩展 ID、手动清理数据也不等于更新。浏览器策略、网站权限限制或测试目录被删除可导致扩展无法运行，不能保证任意外部环境下永远不被停用。

时间同步选项在 0.20.86 及以前的页面初始化中被主动取消；0.20.87 按课程保存 `subtitle-sync:<course>` 的 `autoSync`、`manual` 和 `anchors`。刷新恢复该课程的自动校准选择，手动微调和主动取消勾选继续保持停止。恢复选项先按播放时长倒计时，不会刷新后立刻录音；直播字幕不套用回放定时校准。

已压缩的旧截图缺失像素无法恢复；新后端支持最长边 3840 像素 / 4 MB 的单张静态截图；旧后端缺少高清能力时仍按 1600 像素 / 1.5 MB 上传，预览按视窗比例缩放。此流程不渲染整个网页。

依据：[Chrome Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage)、[Chrome 扩展更新生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/extensions-update-lifecycle)；项目位置为 `extension/adapter.js`、`extension/background.js`、`build-extension.cjs`、`gateway-client.js`、`ai-learning.js`、`cache-storage.js` 及 `backend/server.py`。


## 0.20.90 收藏与同浏览器登录衔接

截图只有明确点击「收藏」才会上传。客户端核对服务器返回的 `ok` 和图片 ID 后显示「已收藏」，保存链接携带图片 ID 直接进入收藏夹；链接不包含登录令牌。失败保留原截图供重试或下载，同一账号重试使用原 ID，切换账号后需重新明确收藏。已打开收藏页回到前台会刷新列表，保留筛选；读图期间延后至关闭阅读器刷新。

安装新版完整扩展后，在同一浏览器配置打开官方学习页或账号页，会由扩展后台申请独立网页会话。网页不接收扩展长期令牌，网页会话存于当前标签页的 sessionStorage，最长24小时且不超过扩展父会话剩余时间，只能查看和整理本人的学习记录；不能调用模型或管理接口。网页退出保留扩展登录；扩展退出、父会话到期或被撤销后，派生网页会话随之失效。手机、无扩展的浏览器及不同浏览器配置仍需正常登录。

收藏画廊桌面双列、手机单列，底部一行显示名称、课程、时间及笔记摘要；「显示名称」选择保存在该网站本机 localStorage。可见卡片最多并行两张加载私有原图，离屏恢复缩略图，退出或切账号会清除展示并忽略迟到响应。已丢失的旧图或旧压缩像素无法据此恢复。
